## About this Repository

This repo is the source for the portfolio site at https://srihari-sirisipalli.github.io. Static React SPA deployed to GitHub Pages.

### Stack
React 18 · TypeScript · Vite · Tailwind · framer-motion · wouter (routing) · @mdx-js/rollup (case studies) · recharts (case-study charts)

### Routes
- `/` Condensed identity (Hero + featured stats + featured work + about teaser + contact CTA)
- `/work` Full project landing with type chips, tech multi-select, search, and URL-synced filters
- `/work/:id` Project deep dive (case study, MDX-authored)
- `/experience` Career timeline + role deep dives + capability matrix
- `/about` Long-form bio + stats + skills + education + leadership
- `/contact` Form + Calendly + socials

### Run locally
```bash
npm install
npm run dev      # Vite dev server, root is client/, alias @ resolves to client/src
npm run build    # tsc typecheck then vite build to dist/
npm run preview  # serve the production build locally
```

### Deployment
`.github/workflows/deploy.yml` deploys to GitHub Pages on every push to `main`: runs `npm ci && npm run build` and uploads `dist/` as the Pages artefact. `client/public/.nojekyll` and `client/public/404.html` (with SPA redirect) ship with the build.

### Adding a case study
Drop a new `client/src/case-studies/<project-id>.mdx` file where `<project-id>` matches a `PortfolioProject.id` in `client/src/data/projects.ts`. The site discovers it automatically via `import.meta.glob` and surfaces a "Read case study" link on the matching project card. Custom MDX components (`Diagram`, `MetricRow`, `ResultsChart`, `Callout`) are pre-injected via `MDXProvider`.
