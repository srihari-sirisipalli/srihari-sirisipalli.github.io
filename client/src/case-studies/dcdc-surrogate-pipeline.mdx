## The problem

Analytical state-space solvers for multi-input DC-DC power converters are accurate and slow. Slow enough that design-space exploration and inverse design (given a target performance envelope, back out the passives and duty cycles) is impractical at any meaningful resolution.

The brief: build an ML surrogate that predicts converter steady-state and small-signal behaviour in microseconds, add uncertainty quantification so it can be trusted at the edges of its training envelope, and wire an inverse-design loop on top so engineers can specify a target and get a candidate design back.

## Dataset

Five thousand samples via Latin Hypercube over 13 inputs (dual voltages, duty cycles, passive component values). Twelve outputs per sample: steady-state operating point, small-signal gain matrix entries, and the relative gain array. Every sample comes from the analytical solver, so ground truth is definitionally correct.

## Model comparison

Four problem formulations crossed with three model families (Random Forest, XGBoost, MLP). Twelve variants total, each swept over depth and regularisation. XGBoost won on the held-out test. The MLP came within a whisker with a physics-informed twist described below.

## Physics-informed network

A physics-informed MLP enforces the relative gain array row-sum identity as a soft constraint in the loss. That single constraint keeps the network from drifting into physically impossible predictions in undersampled regions of the input space, which happens more often than the aggregate error metric suggests.

## Five-layer OOD detector

The surrogate is only trustworthy inside the training envelope. A five-layer out-of-distribution detector wraps every prediction:

- **Mahalanobis distance** in the input feature space
- **Ensemble variance** across model heads
- **Physics residuals** from the RGA constraint
- **Bounds checks** on each input feature
- **RGA consistency** between predicted and reconstructed

Any prediction that fails two or more layers is flagged. The surrogate is a fast approximator, not an oracle.

## Inverse design

Differential evolution over the surrogate: specify a target output vector, get back a candidate parameter set in around 5 to 10 seconds per query. PyQt5 GUI wraps the loop for engineers who want to pin some parameters and search over the rest.

## Reproducibility

A 16-script experiment suite reproduces every result from raw dataset through paper-ready outputs (92 figures, 63 LaTeX tables, seven IEEE-Transactions paper drafts). Reproducibility is the point: an ML paper without a reproducible pipeline is a claim, not a result.

## What broke

The first surrogate looked great on average error and poor on the RGA identity. Aggregate metrics hid a physics violation that a small check caught in one pass. The RGA constraint went into the loss the same day. Lesson: physical invariants belong in the loss function, not in the post-hoc audit.
