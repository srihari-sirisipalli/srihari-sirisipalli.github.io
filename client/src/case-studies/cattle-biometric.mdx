## The problem

Individual cattle identification is a hard technical problem: no two animals are the same, muzzle prints and coat patterns are visually distinctive but noisy, and any workable system has to run at herd scale with low query latency.

## What I built

A multi-view biometric retrieval system for cattle. Given a query image, it returns the most visually similar animals from an index of over one hundred thousand images, ranked by embedding distance.

## Technical design

**Multi-view representation.** Each animal is represented by several views (muzzle, side, face). Single-angle queries still match reliably because the index contains multiple canonical views per identity.

**Contrastive embeddings.** SimCLR-style self-supervised training produces an embedding space where images of the same animal cluster tightly and images of different animals separate. No hand-labelled pairs required beyond identity tags.

**FAISS multi-index retrieval.** The embedding index is sharded and combined with ranking fusion so top-k retrieval stays sub-second at 100K+ scale. Multi-index handles the trade-off between recall and query latency.

**Distributed feature extraction.** Enrolment throughput is fanned out across a 20-worker process pool. New animals are indexed in batch without blocking retrieval traffic.

## What generalises

The same pipeline shape works for any biometric retrieval problem with a stable visual signature: consistent multi-view capture, contrastive embedding training, FAISS at scale, distributed enrolment. The specifics of muzzle prints are a detail; the retrieval architecture is transferable.
