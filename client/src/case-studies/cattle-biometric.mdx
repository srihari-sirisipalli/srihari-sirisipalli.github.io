## What it is

Goodhar. A cattle biometric identification system built for a state agritech initiative, at herd scale. The system identifies individual animals from images so that ownership, health records, and subsidy tracking can attach to a specific animal instead of a tag or a form.

## Status

Currently on hold, in the data-collection phase.

Field teams are running a companion app for image capture. The app handles image filtering (quality, angle, lighting checks) and per-animal registration, so the dataset that will train the production models comes in clean. Retrieval, pipelines, and model benchmarking are already built and validated on the pilot corpus. Work resumes at full scale once the collection window closes.

## What is already built

**Multi-view representation.** Each animal is represented by several canonical views (muzzle, side, face). Single-angle queries still match reliably because the index carries multiple views per identity.

**Contrastive embeddings.** SimCLR-style self-supervised training produces an embedding space where images of the same animal cluster tightly and different animals separate. No hand-labelled pairs required beyond identity tags.

**FAISS multi-index retrieval.** The embedding index is sharded and combined with ranking fusion so top-k retrieval stays sub-second at 100K+ scale. Multi-index handles the recall-vs-latency trade-off.

**Distributed feature extraction.** Enrolment throughput is fanned out across a 20-worker process pool. New animals index in batch without blocking retrieval traffic.

**Model benchmarking.** Backbone comparisons, augmentation ablations, and retrieval-metric sweeps done end to end. The winning configuration is frozen and waiting for the full dataset.

## The field app

The registration app is the piece that is live right now. Operators capture animals in the field, the app runs quality gates (blur, angle, occlusion, lighting), and only accepted frames enter the enrolment queue. Bad data does not get into training, which is the whole point of running collection this way.

## What generalises

The same pipeline shape works for any biometric retrieval problem with a stable visual signature: consistent multi-view capture, contrastive embedding training, FAISS at scale, distributed enrolment, and a strict field-side quality gate. The specifics of muzzle prints are a detail; the retrieval architecture is transferable.
