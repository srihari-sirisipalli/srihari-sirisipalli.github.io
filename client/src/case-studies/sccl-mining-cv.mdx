Upcoming. Currently in the pre-implementation phase.

## What it is

An end-to-end computer vision system for large-scale mining operations. Eleven analytics features running against a live camera estate, wired into a Network Operations Centre dashboard that operators actually sit in front of.

## The eleven detection features

Each one is a first-class module in the analytics backend. All eleven ship together, all eleven run continuously against the camera feeds.

- **PPE detection.** Hardhat, high-visibility vest, boots. Per-zone compliance scoring, per-worker miss counts.
- **ANPR.** Automatic number-plate recognition on entry, exit, weighbridge, and internal checkpoints. Vehicle registry lookup and access-list enforcement.
- **Vehicle counting.** Directional counts per gate, per hour, per shift. Flow anomalies flagged in the log.
- **Headcount.** Zone-level headcount for muster, evacuation, and shift changeover. No individual identification, only aggregate counts.
- **Perimeter monitoring (Sentinel).** Fence-line breach detection with dwell filtering to suppress false triggers from wildlife and weather.
- **Change detection.** Frame-over-frame delta on static scenes to surface object appearance, disappearance, or displacement in restricted areas.
- **Dust-plume detection.** Airborne particulate detection at drill and blast zones for compliance and equipment triggering.
- **Conveyor flow.** Belt-loaded vs. empty classification, throughput proxy, jam detection.
- **Stockpile volume estimation.** Multi-view volumetric estimate for stockpile inventory tracking, timestamped.
- **Thermal anomaly detection.** Hot-spot detection on equipment and stockpiles via thermal camera feed.
- **Drone GPS playback.** Time-synced drone flight paths overlaid on the estate map for post-event review.

## The NOC dashboard

Built in Dash. Seven views, all wired to the same analytics backend, all live.

- **Estate map.** All sites plotted, camera counts, active alerts.
- **Per-site view.** Camera roster, zone map, current shift KPIs.
- **Drone HUD.** Live drone feed with detection overlays and GPS track.
- **Camera mosaic.** Multi-camera grid, up to sixteen tiles, detection-boxed live.
- **Camera detail.** Single-camera focus with historical timeline scrubber.
- **Shift log.** Event stream by shift, filterable by feature and severity.
- **Audit trail.** Every event write, every operator action, timestamped and non-editable.

## Technical build

- **Python analytics package.** One package, one CLI, one config. Each detection feature is a plug-in module conforming to a shared interface. Add a feature by dropping in a new module.
- **Camera ingestion.** RTSP feeds with per-camera worker processes. Frame dropping when downstream backs up, so operator latency stays bounded.
- **Model serving.** Detection models run in-process for latency-critical features (PPE, ANPR, perimeter) and via queue workers for batch-heavy features (stockpile, thermal).
- **Storage.** Events go to a hot store for the dashboard, cold store for the audit trail, and derived aggregates for the KPI cards.
- **Dashboard.** Dash for the UI, WebSocket bridge for live tiles, REST for historical queries.
- **Simulator mode.** The whole thing runs off a scripted simulator without a live camera estate for demos and CI.

## The design constraint

Every feature is buildable, wired, and testable in the simulator before it hits a real camera. That kept the delivery honest: nothing on the dashboard was aspirational, every tile had a working feature behind it.
